# 朝暮田事 · 微信原生小程序

给生活，留一方自己的田地。

## 在微信开发者工具中运行

导入上一级项目目录 `zhiyun-prototype`，保留现有 AppID。根目录 `project.config.json` 已设置 `miniprogramRoot: "miniprogram/"`，编译入口为 `pages/index/index`。不需要 npm 构建，不依赖网页服务器。

项目文件夹保留原路径，便于已经打开的开发者工具继续识别；应用名称、导航标题和分享标题统一为“朝暮田事”。公众号平台上的正式小程序名称仍需在账号后台设置，本次未修改平台信息。

## 新视觉与自由配色

默认“麦田来信”：暖米色背景、麦穗金主色、暖黄点缀。首页采用田垄图形、双列横向植物卡片和“发现 / 田地 / 书房 / 我的”导航。

配色入口在首页右上角“换个心情”，以及“我的 → 主题与自由配色”。

- 6 套预设：麦田来信、松野微风、雾蓝清晨、陶土日落、莓果花笺、月下田园。
- 自由搭配：8 个主色、6 个底色、8 个点缀色，共 384 种原始组合。
- 随机灵感：自动挑选一组主色、底色和点缀色。
- 实时预览：调整后，当前配色工作台即时变化。
- 保存后全局生效并保留到下次进入；直接返回则恢复原先保存的主题。
- 自动计算按钮文字的深浅，必要时校正主色与底色的对比，支持夜色底色。

## 功能

植物推荐、搜索、分类、植物手册、添加种植、本地种植空间、种植档案、养护动作、照片与文字日记、日记搜索、今日观察待办、播种日历、小词典。

## 地点、天气、登录与交流的当前状态

- 首页地点、田地类型与时节改为独立卡片，避免长文字和箭头堆叠；地点可手动命名，或在微信地图中选择。
- 首页天气卡片和晴、多云、雨、雪绘本动效已完成。客户端已请求 Cloudflare 天气接口，但天气服务商密钥尚未配置；当前仍是本地动效预览。
- 已在 `app.json` 声明定位用途；仅在用户点“在地图中选择地点”时才触发位置选择，地点保存到本机。
- 小程序已连接 `https://chaomu-api.hibutuo.com`。植物目录优先读取 D1 中的 12 条自编资料，断网时回退本机资料。微信登录客户端与 Worker 密钥已配置，实际登录成功仍需在微信真机上验证。
- “登录与云端田地”“田边交流”入口已加入“我的”页。云同步、社区发布和收费尚未开放。
- 详细接口、数据源和上线顺序见上一级《服务接入蓝图.md》。

## 自然绘本 · 生长剧场

首页“看一粒种子的故事”进入，也可从“我的 → 生长剧场”或小番茄、生菜、长寿花的植物手册进入。

- 三种植物各有五个章节，支持播放、暂停、重播、拖动和点选章节。
- 生菜表现长叶与采收，长寿花从小苗／扦插开始，小番茄呈现开花结果。
- 可关闭轻动效；离开页面、切到后台时自动停止播放。
- “我的田地故事”整理当前植物类别的本机档案、日记和照片数量，不生成虚构记录。
- 动画是本地编写的绘本模拟，尚未接入 AI 生成、收费或云端上传。后续创意见上一级《产品创意与差异化.md》。

添加种植中，“直接播种 / 育苗移栽 / 移栽”与种子、苗、扦插、分株来源联动。结束本轮种植后，保留档案和日记。移除植物不会删除已有日记。

记录与配色使用微信本地存储，键名 `yifangtiandi-native-v1`。网页原型与小程序数据独立。照片选择使用微信原生媒体接口，保存在小程序本地文件空间。

## 当前边界

植物目录已接入 Cloudflare Worker 与 D1，微信登录服务端已准备好，真机登录待验收。尚未接入跨设备同步、订阅消息和实况天气服务商。每日待办为本机观察事项，不发送真实消息。植物资料、播期和推荐排序为设计示例，上线前需专业校对和完整地区模型。
