# 朝暮田事 · 微信小程序

在微信开发者工具中导入仓库根目录。入口位于 `miniprogram/pages/index/index`。运行 `npm test` 可检查小程序逻辑和打包资源。

基础图鉴照片随小程序发布。点开大图时，小程序向服务端请求经过核对的高清照片或后台审核后发布的替换图。

`main` 保存稳定版本。`develop` 用于日常开发，功能分支从这里创建，测试和审查后合并。发布时给 `main` 的提交增加版本标签，并更新 [版本记录](./CHANGELOG.md)。
